# GLORIFIER AI Coding Fleet

Mission: keep the GLORIFIER codebase healthy, secure, tested, documented, and incrementally improved.

Rules:
1. Never expose or commit secrets, API keys, database URLs, tokens, cookies, or private credentials.
2. Work only on the assigned branch and keep changes small.
3. Run type-check/build validation when applicable.
4. Never bypass CI or security checks.
5. Never deploy directly from an autonomous coding task; use pull requests.
6. If a task is ambiguous or destructive, document the blocker instead of guessing.

Roles: Architect (reliability/architecture), Security (verified security/dependency risks), QA (tests/types/builds/error handling), Frontend (UI/accessibility/performance), Integrations (GitHub/npm/Railway/Vercel/Netlify/Neon/web/AI boundaries).
