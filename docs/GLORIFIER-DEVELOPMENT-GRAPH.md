# GLORIFIER Development Graph

The development graph links software changes to operational and business outcomes.

**Issue → Objective → Plan → Agent → Branch → Commit → PR → CI → Security → Approval → Deployment → Telemetry → Evidence → Outcome**

Each edge should be attributable and timestamped. Failed runs, rollbacks, rejected approvals, and disputed evidence are first-class events.

This graph complements the Neon authoritative economic ledger; it does not replace it.
